# Agent notes

Chipboy Studio is a Vite + React 19 + TypeScript chiptune studio. All audio runs in the browser through the Web Audio API. There is no backend.

## Commands

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm dev          # port 8080
corepack pnpm check        # lint + typecheck + test + build
corepack pnpm test         # Vitest, Node environment
corepack pnpm android:sync # web build + cap sync android
corepack pnpm android:debug
corepack pnpm android:release
corepack pnpm fdroid:lint   # requires fdroidserver
```

`corepack pnpm` is used when `corepack enable` cannot write globally.

## Layout

- `src/App.tsx` — base-path route check, error boundary, tooltip and toast providers.
- `src/pages/` — `Index` and `NotFound`.
- `src/components/WorkspaceLayout.tsx` — console shell and five mode tabs. Inactive tabs stay mounted with `hidden`.
- `src/components/StudioProvider.tsx` — single source of truth: song, selection, samples, playback.
- `src/lib/song.ts` — plain song types and arrangement helpers.
- `src/lib/project.ts` — Zod schemas, v5 file format, share links, `localStorage`.
- `src/lib/riffs.ts` — built-in riff library, custom-riff storage and preview helpers.
- `src/lib/audio-engine.ts` — live scheduling and offline render.
- `src/lib/sample-processing.ts`, `wav.ts`, `effects.ts`, `instruments.ts` — pure domain modules.
- `src/lib/native.ts` — the only file that imports Capacitor plugins. Exposes `initNativeShell`, `saveBlob`, `shareLink` and `tapHaptic` with web fallbacks.
- `capacitor.config.ts` — Capacitor app ID, web dir, splash and status-bar colours.
- `android/` — checked-in Capacitor Android project. `android/app/build.gradle` holds version and signing config.
- `fdroid/` — fdroiddata recipe; `fastlane/metadata/android/` holds store listing files.
- `licenses/` — full OFL texts for the bundled fonts; summary in `THIRD_PARTY_LICENSES.md`.
- `src/components/RiffLibrary.tsx` — riff browsing, preview, stamping and capture.
- `src/test/setup.ts` — minimal `AudioBuffer` polyfill for Vitest.

## Rules that matter

- Never put `AudioBuffer` in the song or in project files. Use `sampleId`.
- `stepSeconds(song)` is the only BPM-to-time conversion.
- Live playback and WAV export must use the same scheduling path and per-channel effect buses.
- Validate and normalize every imported project; reject files over 2 MB.
- Keep the sampler and project data local. Do not add analytics or uploads.
- Respect `prefers-reduced-motion`.
- Keep custom riffs note-only; never store `AudioBuffer` objects.
- Keep Capacitor imports inside `src/lib/native.ts`; components should stay web-safe.
- Run `corepack pnpm check` before finishing a change.
- Run `corepack pnpm android:sync` after web changes and before testing the APK.
- Bump `versionCode` and `versionName` in `android/app/build.gradle` for every Android release.
- Never commit a keystore, `signing.env` or a signed APK.

## Known environment quirks

- Vite rejects unknown hosts in dev; set `VITE_ALLOWED_HOSTS=host1,host2`.
- Subpath builds use `VITE_BASE_PATH=/repo-name/`; the route check and manifest follow `BASE_URL`.
- Icons are generated by `scripts/generate-icons.py` with Pillow and the Press Start 2P TTF. It also writes `resources/` and Android launcher densities.
- Android builds need JDK 21 and `ANDROID_HOME`; set both before Gradle.
- Release signing uses `CHIPBOY_KEYSTORE_PATH`, `CHIPBOY_KEYSTORE_PASSWORD`, `CHIPBOY_KEY_ALIAS` and `CHIPBOY_KEY_PASSWORD`. CI maps them from `ANDROID_*` secrets.
- F-Droid's canonical metadata repo is GitLab `fdroid/fdroiddata`, not GitHub. The recipe is in `fdroid/`. The recipe passes `fdroid lint`; the clean build from `v1.2.0` produced an unsigned APK with no internet permission. The MR is open at `fdroid/fdroiddata!58500`; the fork is `ones-is-lord/fdroiddata`. The summary lives in `fdroid/en-US/summary.txt`, not in the YAML. Do not invent credentials.
- The `android/` directory is ignored by ESLint; do not add native code to the web lint target.
